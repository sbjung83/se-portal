[1] 개요
----------------------------------------------------------------
- 이름   : SE Portal (서버 엔지니어 업무 관리 포탈)
- 위치   : /opt/se-portal
- 구성   : FastAPI(백엔드) + SQLite(DB) + 바닐라 JS SPA(프론트)
- 운영   : Rocky Linux 9 / systemd(se-portal.service) + nginx(80 → 8000)
- 실행 계정: appuser
- 주요 패키지: fastapi 0.111, uvicorn 0.29, sqlalchemy 2.0, jinja2,
              python-multipart, aiofiles, openpyxl(install.sh에서 설치)

[3] 요청 흐름
----------------------------------------------------------------
 브라우저 → nginx:80 → uvicorn:8000 (app.py)
   "/"         → templates/index.html (SPA 한 장)
   "/static/*" → static/
   "/api/*"    → routers/*.py → database.get_db() → data/portal.db
   "/api/dev/*"→ data/portal-development.json (DB 아님)


[4] API 경로 규칙
----------------------------------------------------------------
 /api/auth/{register|login|logout|me}
 /api/engineers/{eng_id}/dashboard
 /api/engineers/{eng_id}/sites[/{site_id}/devices|accesses|reports|notes]
 /api/engineers/{eng_id}/schedules[/history|/all]
 /api/engineers/{eng_id}/issues
 /api/engineers/{eng_id}/site-checklist[/{site_id}|/reset/{site_id}]
 /api/engineers/{eng_id}/projects[/{id}/tasks]
 /api/engineers/{eng_id}/logs
 /api/engineers/{eng_id}/technotes
 /api/engineers/{eng_id}/workplans[/{id}/download]
 /api/dev/checklist[/summary|/stats|/section/..|/status/..|/item/{id}]

 → 엔지니어 소유 데이터는 전부 /api/engineers/{eng_id}/ 하위.
 → 쿼리마다 engineer_id == eng_id 로 필터.


[5] DB 모델 (database.py)
----------------------------------------------------------------
 users          (id, username, password[sha256], engineer_id)
 engineers      (id, name, memo)
 sessions       (id, user_id, engineer_id)   ← 로그인 세션 토큰
 sites          (engineer_id, name, location, manager, contact, memo)
   ├ devices    (site_id, name, model, serial_no, dev_type, os, warranty, status ...)
   ├ accesses   (site_id, ip, port, protocol, username, password ...)
   ├ reports    (site_id, filename, stored_name, size, uploaded_at)
   ├ notes      (site_id, date, title, body)
   ├ schedules  (site_id, engineer_id, title, sched_date, sched_type, status)
   ├ issues     (site_id, engineer_id, title, body, severity, status)
   └ site_checklists (site_id, engineer_id, category, text, done)
 worklogs       (engineer_id, date, site[문자열], log_type, title, body)
 workplans      (engineer_id, title, work_date, purpose, impact, mop_content,
                 verification, rollback_plan, status ...)
 projects       (engineer_id, name, customer, start/end_date, status)
   └ project_tasks (project_id, name, status, start/end_date, order_idx)
 technotes      (engineer_id, title, category, tags, body[마크다운])

 * PK 는 모두 uuid4 문자열
 * 날짜는 대부분 "YYYY-MM-DD" 문자열
 * Site 삭제 시 하위 데이터 cascade 삭제
 * init_db() = create_all → 새 테이블만 생성, 컬럼 변경은 수동 ALTER 필요


[6] 상태값 (한국어 고정 문자열)
----------------------------------------------------------------
 점검일정  status : 예정 / 완료        type : 월간 / 분기 / 특별
 이슈      severity: 긴급/높음/보통/낮음  status: 오픈 / 처리중 / 완료
 프로젝트  status : 진행 대기 / 진행 중 / 보류 / 완료
 태스크    status : 대기 / 진행중 / 완료
 체크리스트 category: 일반 / 월간 / 분기
 작업계획  status 기본값: 계획중
 개발체크  status : 예정 / 진행중 / 완료


[7] 백엔드 코딩 패턴
----------------------------------------------------------------
 - router = APIRouter(prefix="...", tags=[...])
 - db: Session = Depends(get_db)
 - 입력: XxxIn (생성), XxxUpdate (수정, 전부 Optional)
 - PATCH: data.dict(exclude_none=True) → setattr
 - 응답: _xxx_dict() 헬퍼로 dict 변환
 - 삭제 응답: {"ok": True} / 없으면 HTTPException(404)
 - 에러 메시지는 한국어
 - 새 라우터는 app.py 에 import + include_router 필수


[8] 프론트엔드 구조
----------------------------------------------------------------
 - 화면 전환: 사이드바 .nav-item[data-page=X] 클릭
              → #page-X 활성화 → app.js 에서 renderX() 호출
 - 페이지: dashboard, sites, checklist, projects, proj-status,
           schedule-mgmt, sched-history, work-plan, logs, report(미구현),
           technotes, dev-checklist
 - 모달: .overlay#modal-xxx + openModal()/closeModal()
 - 공통 헬퍼: $(id), api.get/post/patch/del, toast(), renderPagination()
 - 전역 상태: ENG_ID, ENG_NAME (로그인 후 /api/auth/me 로 복원)
 - 함수명 규칙: renderXxx / openAddXxx / openEditXxx / saveXxx / deleteXxx
 - CDN: marked(기술노트 마크다운), highlight.js
 - 캐시버스팅: index.html 의 app.js?v=2
